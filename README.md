# 🐑🧜‍♀️🐰🐯 한국특허정보원 카드배틀

맵 네 모서리의 장소에서 카드를 뽑아 중앙 동물 스택에 쌓고, 짝수 장이 모이는 순간 획득하는 할리갈리/고스톱류 실시간 N:N 팀 대전 웹 게임입니다. 4대 지식재산권(실용신안·상표·디자인·특허)의 성격을 그대로 체화한 아기 동물 카드 4종이 등장합니다.

- 🐑 **실용신양** (실용신안 + 양) — 선택 시 다음 내 턴에 카드를 (레벨)회 더 뽑음
- 🐰 **상표토끼** (상표 + 토끼) — 선택 시 내 총점의 `5% × 레벨`만큼 획득
- 🧜‍♀️ **디자인어** (디자인 + 인어) — 선택 시 상대와의 총점 차이의 `5% × 레벨`만큼 획득
- 🐯 **특허랑이** (특허 + 호랑이) — 선택 시 상대 총점의 `5% × 레벨`만큼 감소

## 게임 방법

1. **장소 클릭 → 카드 뽑기**: 맵 네 모서리(오두막·숲길·부둣가·강가)에는 각각 나올 수 있는 동물이 정해져 있습니다. 장소를 클릭하면 슬롯머신처럼 동물과 숫자가 돌다가 확정되어, 중앙의 해당 동물 스택으로 날아갑니다.
2. **짝수 장이 모이면 즉시 획득**: 중앙 스택에 같은 동물 카드가 짝수 장 쌓이면 그 순간 전부 획득하고 숫자 합만큼 점수(=경험치)를 받습니다. 정산은 이번 차례에 뽑을 카드를 모두 뽑은 뒤(실용신양으로 예약된 추가 뽑기 포함) 한 번에 이루어집니다.
3. **턴 종료 시 스킬 하나 선택**: 정산까지 끝나면 4가지 스킬(아래 표) 중 하나를 반드시 골라야 턴이 상대에게 넘어갑니다. 효과 크기는 그 동물의 **레벨**(`floor(점수 / 임계값)`, 실용신양·상표토끼는 10점당 1레벨, 디자인어·특허랑이는 20점당 1레벨)에 비례합니다.
4. **14턴이 지나면 도토리 폭탄 등장**: 15턴부터 카드를 뽑을 때마다 확률적으로 도토리 폭탄이 터져 그 동물의 미획득 스택 전체가 날아갑니다. 확률은 15턴 30%에서 시작해 턴이 오를 때마다 3%씩 증가합니다.
5. **30턴 종료 시 최종 판정**: 4개 동물 점수 총합이 더 높은 팀이 승리합니다(동점이면 무승부).

인게임 우측 상단 `?` 버튼(게임 방법)을 누르면 실제 화면을 그대로 재연한 안내 모달을 볼 수 있습니다.

### 스킬 4종 상세

| 동물 | 효과 |
|---|---|
| 🐑 실용신양 | 다음 내 턴에 무작위 장소에서 카드를 `레벨`회 더 뽑음(즉시 점수 변화 없음) |
| 🐰 상표토끼 | 내 총점의 `5% × 레벨`만큼 상표토끼 점수에 더함 |
| 🧜‍♀️ 디자인어 | 상대와의 총점 차이의 `5% × 레벨`만큼 디자인어 점수에 더함(뒤처져도 앞서도 동일 공식) |
| 🐯 특허랑이 | 상대 총점의 `5% × 레벨`만큼 상대 점수를 동물별 비중대로 차감(0 밑으로는 내려가지 않음) |

선택 모달의 각 항목 아래에는 "내 점수 +nnnn점" / "상대 점수 -kkkk점"처럼 실제로 계산된
값이 미리 표시됩니다. 레벨이 0인 동물을 고르면 효과가 없습니다.

게임 규칙과 밸런스 수치의 더 자세한 유도 과정은 [`ROADMAP.md`](./ROADMAP.md)를 참고하세요(초기 설계 문서로, 이후 장소/뽑기 방식·스킬 선택제·도토리 폭탄 등으로 개편된 최신 규칙은 이 README와 실제 코드가 기준입니다).

## 기술 스택

- **클라이언트**: Next.js (App Router) + TypeScript + Tailwind CSS
- **서버**: Node.js + WebSocket (`ws`) — 게임 상태의 유일한 진실(Source of Truth)
- **공유**: `/shared` — 타입·상수·WebSocket 프로토콜 (클라이언트·서버 공용)

핵심 설계 원칙:
- 카드는 뽑히는 즉시 공개되므로 숨길 정보가 없고, 모든 랜덤(뽑힌 동물·숫자, 실용신양 추가 뽑기 장소, 도토리 폭탄 발동 여부)은 서버에서만 생성
- 30초 턴 타이머는 서버가 `turnDeadline` 타임스탬프로 관리, 클라이언트 타이머는 표시 전용
- 카드 "재고"나 "보충" 개념은 없음 — 뽑기는 언제나 무한

## 디렉토리 구조

```
card_battle/
├── shared/          # 타입·상수·WebSocket 프로토콜 (양쪽에서 공유)
├── server/          # Node.js 게임 서버 (WebSocket, 룸 관리, 게임 엔진)
│   └── engine/      # 순수 게임 로직 (UI와 완전 분리, 단위 테스트 대상)
│       ├── places.ts       # 장소별 동물/숫자 규칙, 스택 초기화
│       ├── drawCard.ts     # 예약된 추가 뽑기 소모 → 뽑기 → 폭탄 판정 → 정산까지의 단일 진입점
│       ├── skills.ts       # 턴 종료 스킬 4종(레벨 기반 효과 계산)
│       ├── turnManager.ts  # 턴 교대, 도토리 폭탄 활성화(15턴), 종료 판정
│       └── gameEngine.ts   # processPlayerAction(뽑기) → processSkillChoice(스킬 선택) 2단계 진입점
└── client/          # Next.js 앱 (로비·게임 화면·애니메이션)
    ├── components/game/    # 보드·장소 타일·동물 스택·점수판
    ├── components/effects/ # 슬롯머신, 울 볼, 도토리 폭탄, 이모티콘 등 연출 레이어
    └── hooks/useAnimationQueue.ts  # 서버 이벤트 → 연출 타임라인 스케줄러
```

## 시작하기

터미널 두 개를 열어 각각 실행합니다.

```bash
# 터미널 1 — WebSocket 게임 서버 (포트 8080)
cd server
npm run dev

# 터미널 2 — Next.js 클라이언트 (포트 3000)
cd client
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 후, 방을 만들고 다른 브라우저(또는 시크릿 창 — 같은 브라우저의 새 창은 세션 정보를 공유해 충돌합니다)로 참가하면 대전을 시작할 수 있습니다.

### 사운드 에셋 (선택)

`client/public/sounds/`에 아래 접두사로 시작하는 mp3 파일을 넣으면 해당 동물 효과 발동 시 무작위로 재생됩니다 (파일이 없어도 무음으로 정상 동작).

| 파일명 접두사 | 발동 시점 |
|---|---|
| `card_*.mp3` | 장소에서 카드를 뽑을 때마다 |
| `sheep_*.mp3` | 실용신양 스킬로 예약된 추가 뽑기 카드마다 |
| `mermaid_*.mp3` | 디자인어 스킬 발동 시 |
| `tiger_*.mp3` | 특허랑이 스킬 발동 시 |
| `rabbit_*.mp3` | 상표토끼 스킬 발동 시 |
| `bomb.wav`(또는 `bomb_*`) | 도토리 폭탄 발동 순간(없으면 `tiger_*`로 대체) |
| `result.wav` | 게임 종료 화면 표시 시 |

BGM은 `client/public/sounds/bgm_game1.mp3`(1~14턴), `bgm_game2.mp3`(15턴 이후, 도토리 폭탄 등장 시점), `bgm_opening.mp3`(로비·종료 화면)로 전환됩니다.

# /tmp — 임시 에셋 (전부 대체 예정)

이 폴더의 파일은 **로비 레이아웃을 먼저 잡기 위한 자리표시(placeholder)** 이며,
실제 디자인 에셋이 나오면 **전부 교체**되어야 한다.

placeholder임을 한눈에 알 수 있도록 모든 파일에 공통으로
① 대각선 해치 무늬 ② 점선 테두리 ③ 우측 하단 `TMP` 표기 를 넣어 두었다.

| 파일 | 쓰이는 곳 | 대체 시 필요한 것 |
|---|---|---|
| `logo_bg.svg` | 로비 상단 로고 박스 배경 | 게임 로고 (가로:세로 ≈ 10:3) |
| `panel_solo_bg.svg` | 싱글플레이 패널 배경 | 세로형 일러스트 (≈ 5:6) |
| `panel_multi_bg.svg` | 멀티플레이 패널 배경 | 세로형 일러스트 (≈ 5:6) |
| `panel_create_bg.svg` | 방 만들기 패널 배경 | 가로형 일러스트 (≈ 5:3) |
| `panel_join_bg.svg` | 방 참가하기 패널 배경 | 가로형 일러스트 (≈ 5:3) |

## 교체 방법

경로는 [`client/lib/lobbyAssets.ts`](../../lib/lobbyAssets.ts) 한 곳에만 정의되어 있다.
새 에셋을 `client/public/lobby/` 등에 넣고 그 파일의 경로 상수만 바꾸면 된다.
컴포넌트 코드는 손댈 필요가 없다.

교체가 끝나면 `client/lib/lobbyAssets.ts`의 `TMP_ASSETS_IN_USE` 를 `false`로 바꾼다.
그러면 화면 우측 하단의 "임시 에셋" 배지가 사라진다. 이 폴더도 함께 삭제한다.

> 로고는 아직 확정 에셋이 없다 (`LOBBY_REDESIGN.md` §7-1 결정 대기).
> 그때까지는 이 배경 위에 이모지 4종 + 텍스트 제목이 얹혀 렌더링된다.

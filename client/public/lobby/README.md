# /lobby — 로비 배경 에셋

## 들어 있는 것

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `table_bg.webp` | 3072×1649 / 374KB | 로비 전체 배경 — 네 동물이 둘러앉은 카드테이블 일러스트 |

로고는 `client/public/tmp/logo.png`("떱카드 T.U.P.D." 엠블럼)에 있다.
두 경로 모두 [`client/lib/lobbyAssets.ts`](../../lib/lobbyAssets.ts) 한 곳에서만 참조하므로,
파일을 바꿀 때는 그 상수만 고치면 된다.

### 원본 PNG는 git 이력에 있다

원래 배경은 4096×2198 PNG(12.9MB)였다. 매 접속마다 내려받기엔 너무 무겁고 git 이력에도
버전마다 통째로 쌓이므로 WebP로 줄였다(34배 감소, 육안상 차이 없음).
원본이 필요하면 이력에서 꺼낼 수 있다.

```bash
git show b14caba:client/public/lobby/table_bg.png > table_bg.png
```

해상도를 다시 정할 일이 있으면 참고할 실측값:

| 가로 | 용량 | 원본 대비 | 선명하게 커버되는 화면 폭 |
| --- | --- | --- | --- |
| 2048px | 183 KB | 1.4% | ~1950px |
| **3072px (현재)** | **374 KB** | **2.8%** | **~2926px** |
| 3840px | 578 KB | 4.4% | ~3657px |

배경은 화면을 꽉 채우므로 투명도가 필요 없다. 테이블은 `cover`로 그려져 화면 가로보다
크게 확대되므로(표시폭 ≈ `max(vw, vh × 1.863)`), 위 표의 "커버되는 화면 폭"은 그 점을
감안한 근사치다.

## 안전영역 — 버튼이 캐릭터를 가리지 않게 하는 좌표

버튼·폼은 캐릭터나 카드더미에 걸리지 않도록 테이블 중앙의 **안전영역** 안에만 놓인다.
좌표는 이미지 크기에 대한 **비율**이라 화면 크기가 바뀌어도 항상 테이블 위에 정확히 붙는다.
값은 전부 [`globals.css`](../../app/globals.css)의 `.lobby-table` 블록에 모여 있다.

```css
.lobby-table {
  --table-w: 3072;      /* table_bg.webp 의 실제 픽셀 크기 */
  --table-h: 1649;
  --safe-left: 26.4%;   /* 실용신양·디자인어, 왼쪽 카드더미를 피함 */
  --safe-right: 29.6%;  /* 상표토끼·특허랑이, 주머니, 오른쪽 카드더미를 피함 */
  --safe-top: 15.9%;    /* 위쪽 램프와 나무 테두리를 피함 */
  --safe-bottom: 14.3%; /* 아래쪽 카드더미 두 개를 피함 */
}
```

배경 이미지를 **다른 구도로** 교체하면 이 6개 값만 조정하면 된다. 컴포넌트 코드는 손댈 필요가 없다.
해상도만 바뀌는 경우에도 `--table-w/h`는 실제 픽셀 크기로 맞춰 두는 편이 좋다(비율만 맞으면
동작은 같지만, 값이 곧 문서 역할을 한다).

좁은 화면(≤767px)에서는 테이블이 크게 확대돼 좌우 비대칭이 화면 이탈을 만들므로,
같은 파일의 미디어쿼리에서 `--safe-left/right`를 `30%`로 대칭 처리한다.

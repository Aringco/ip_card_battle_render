# `오늘의_명령어/` — 날짜별 요청 기록

**무엇을 왜 요청했고, 그래서 무엇이 어떻게 바뀌었는지**를 하루 단위로 남긴 파일들입니다.
2026-09-11에 저장소 루트에 흩어져 있던 것을 이 폴더로 모았습니다.

## 이 기록이 존재하는 이유

커밋 메시지는 "무엇을 바꿨는가"를 남기지만, **"왜 그렇게 바꿨는가"와 "무엇을 해보다
되돌렸는가"** 는 남기기 어렵습니다. 같은 자리를 두 번 세 번 고치는 일이 잦은 작업이라
(에셋 교체·레이아웃 조정), 되돌린 시도까지 적어 두지 않으면 **몇 주 뒤에 같은 길을 다시
걷게 됩니다.** 실제로 "규칙 펼치기"는 하루에 세 번, 나무틀 에셋은 세 번 다시 만들었습니다.

각 파일은 같은 틀을 씁니다.

```
── 이 파일에 넣지 않은 것 ──   제품을 바꾸지 않은 요청(푸시·기록 정리 등)
── 이 날의 큰 줄기 ──          그날을 한 문단으로
[n] 요청 제목                  받은 명령 원문
(→ …)                          그 명령으로 실제로 무엇이 바뀌었는지 · 함정 · 되돌린 것
참고 — 이 날 배운 것            다음에 같은 실수를 피하기 위한 줄들
```
